### ESP32 PC Control Deck

Need a small PC monitoring display with configurable touch macros?
The [ESP32 PC Control Deck](https://esp32-pc-control-deck.lepczynski.it/) has a browser-based firmware installer, so users can flash the supported Elecrow ESP32 touchscreen without setting up PlatformIO. A separate Python PC bridge is required to show CPU/GPU data and launch programs. [Source code](https://github.com/lepczynski-cloud/ESP32-PC-Control-Deck) | [Video](https://www.youtube.com/watch?v=16eqHU4j9Fk)
