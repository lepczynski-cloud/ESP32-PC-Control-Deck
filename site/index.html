FOUR SHORT STEPS

  1. 01

    Connect the device

    Use a USB data cable and a supported desktop browser.

  2. 02

    Flash in your browser

    Choose the CH340 serial port, install and let the board restart.

  3. 03

    Download the PC bridge

    The desktop Python app is required for statistics and touch macros.

  4. 04

    Start and customize

    Run the bridge, then adjust shortcut commands in your local config.

!

Not a standalone monitor. This classic ESP32 uses a CH340 USB serial bridge, not native USB HID. The program on your computer handles the actions.

04 / REQUIRED DESKTOP APP

The screen is only
half of the setup.

A local Python bridge reads your computer's metrics and sends them to the ESP32 over USB. It also receives touch events and launches shortcuts you define.

Download PC bridge ↓

No internet or account required for runtime. Python 3 is needed on the computer.

PC BRIDGE / QUICK START
WINDOWShost\run_windows.bat

Creates a virtual environment and starts the program.

MACOS / LINUXsh host/run_linux_macos.sh

Start the USB serial bridge in a local terminal.

CUSTOM SHORTCUTShost/config.json

Configure commands, paths and serial port locally.
