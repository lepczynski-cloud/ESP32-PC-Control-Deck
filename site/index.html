03 / ONE MORE STEP

Flash the screen.
Run the bridge.

Installing firmware is only half the setup. A small Python app runs on your computer, gathers system data and executes the actions you configure. It communicates with the board over USB serial.

PC bridge requiredWithout the PC app, live CPU/GPU data and launch buttons will not work. This classic ESP32 + CH340 board is not a native USB HID keyboard.
Download PC bridge ↓Full setup instructions ↗
